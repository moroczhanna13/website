# Mórocz Hanna – portfólió

Személyes portfólió weboldalam, ahol bemutatom magam, a projektjeimet és a készségeimet, és ahol el is lehet érni. Az oldal magyarul és angolul is olvasható, világos és sötét témával. A dizájnt egy kártyapakli ihlette: minden projekt egy megfordítható kártyalap. React, TypeScript és Vite felhasználásával készült, és GitHub Pagesen fut.
